# Math Maze V2

Segunda versión experimental del Laberinto Matemático del Científico.

## Cambios respecto a la versión original
- Arquitectura separada: HTML, CSS y JavaScript.
- Retos matemáticos mediante interfaz propia, sin `prompt()`.
- Opciones múltiples para responder.
- Indicador de puntos, vidas y porcentaje de aciertos.
- Soporte de teclado con flechas y WASD.
- Progresión de cuatro niveles con dificultad creciente.
- Rama independiente para conservar intacta la versión original.

## Ejecutar
Abrir `v2/index.html` desde un servidor local o GitHub Pages.
